# Mechanisoul

**Role:** Lead Programmer – Character & Combat Systems  
**Studio:** DreamStatic Studios (Internal Project)  
**Duration:** Aug 2025 – Present  

---

## Overview

*Mechanisoul* is an action-focused game featuring dynamic character movement and responsive hack-and-slash combat. This project emphasizes modularity, animation-driven interactions, and fluid player control to create an engaging and responsive gameplay experience.

---

## Key Features

### Character & Movement
- Modular **character controller** designed for extensible player mechanics.
- Animation-driven interactions for smooth movement and combat transitions.
- Centralized `PlayerManager` to handle health, movement, and upgrades.

### Combat Systems
- **Reusable hack-and-slash framework** using `ScriptableObjects` for weapons, attacks, and effects.
- Hitbox activation tied to **animation events** for precise combat feedback.
- Toggleable **aiming system** supporting both hitscan and projectile-based targeting.
- **Lock-on targeting system** inspired by *Zelda* for fluid camera and input transitions.

### Tools & Architecture
- Modular systems designed for **easy expansion** with new weapons, attacks, and player abilities.
- Centralized management of player-related systems to reduce code duplication and improve maintainability.
